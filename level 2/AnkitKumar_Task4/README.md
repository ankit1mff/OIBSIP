# Oasis Infobyte Web Development Internship - Level 2: Task 4

This is a client-side Login Authentication System built for the Oasis Infobyte Web Development & Designing Internship.

## Project Overview
A secure single-page authentication app featuring user registration with password validation, duplicate checking, credential hashing, login validation, session management, and a protected dashboard page.

## Key Features
* Registration page with form validation and duplicate user checks.
* Strict password policy validation (minimum 8 characters with at least 1 number).
* Secure client-side password hashing using the Web Crypto API (SHA-256) instead of plain-text storage.
* Login page with secure credential verification and generic error messaging.
* Protected dashboard page restricted to active session states with direct URL redirection guards.
* Logout button that clears session data and redirects back to the login page.

## Tech Stack
* HTML5
* CSS3
* JavaScript (Vanilla with localStorage & Web Crypto API)
