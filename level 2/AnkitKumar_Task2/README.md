# Oasis Infobyte Web Development Internship - Level 1: Task 2

This is a visually engaging tribute page dedicated to Dr. A.P.J. Abdul Kalam, built for the Oasis Infobyte Web Development & Designing Internship.

## Project Overview
A responsive and well-structured web page celebrating the life, achievements, and legacy of "The Missile Man of India", featuring original written biography content, a historical timeline, and prominent quotes.

## Key Features
* Page title highlighting the subject's name and tagline.
* Responsive primary image with descriptive caption sourced from public domain imagery.
* Detailed 3-paragraph biographical tribute section.
* Styled chronological timeline of key milestones and achievements.
* Distinctly styled quotation block.
* Multiple background color contrasts across sections.
* Integration of distinct font styles (`Merriweather` for headings and `Open Sans` for body text).
* Fully responsive layout adaptable for mobile viewports.

## Tech Stack
* HTML5
* CSS3
