# Oasis Infobyte Web Development Internship - Level 2: Task 3

This is an interactive To-Do Web Application built for the Oasis Infobyte Web Development & Designing Internship.

## Project Overview
A clean and functional task management interface that allows users to add, edit, complete, and delete tasks, organized separately into pending and completed sections.

## Key Features
* Input field to add new tasks with validation checks.
* Organized two-column layout separating pending and completed tasks.
* Action controls for marking tasks as done/undo, editing text, and deleting.
* Fully responsive layout adaptable for mobile viewports.

## Tech Stack
* HTML5
* CSS3
* JavaScript (Vanilla)
