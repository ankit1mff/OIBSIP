# Oasis Infobyte Web Development Internship - Level 2: Task 1

This is a fully functional browser-based calculator built for the Oasis Infobyte Web Development & Designing Internship.

## Project Overview
A responsive and interactive calculator designed to perform basic arithmetic operations smoothly using vanilla JavaScript logic and CSS Grid formatting.

## Key Features
* Display screen showing real-time inputs and evaluation results.
* Numeric buttons (0-9) along with a decimal point.
* Operator support for addition, subtraction, multiplication, and division.
* Clear (C) and Backspace (DEL) utility buttons.
* Division-by-zero protection with error messaging.
* Operator chaining to execute continuous calculations.
* Clean layout structured via CSS Grid with native JS Event Listeners.

## Tech Stack
* HTML5
* CSS3
* JavaScript (Vanilla)
