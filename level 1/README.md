# Oasis Infobyte Web Development Internship - Level 1: Task 3

This is an interactive Temperature Converter web tool built for the Oasis Infobyte Web Development & Designing Internship.

## Project Overview
This tool converts temperature values seamlessly between Celsius, Fahrenheit, and Kelvin with integrated input validation and absolute zero edge-case handling.

## Key Features
* Numeric input validation to reject empty or non-numeric values.
* Dropdown unit selector for Celsius, Fahrenheit, and Kelvin.
* Simultaneous auto-conversion displaying all output units instantly.
* Absolute zero boundary checks to display user-friendly error messages.
* Clean, centered, and responsive UI layout.

## Tech Stack
* HTML5
* CSS3
* JavaScript (Vanilla)
